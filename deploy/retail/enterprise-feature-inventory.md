# 授权功能盘点与任务覆盖

状态：源码基线清单，功能实现状态以 [任务清单](enterprise-replacement-backlog.json) 为准

更新日期：2026-11-05

源码基线：`e3f8f7d3`

本清单按 [自主替代方案](enterprise-replacement-plan.md) 分批处理。后端 46 项、前端 23 项和商业模块 21 个功能族之间存在重叠，不能相加为独立收费功能数。后端限制包括直接拒绝、忽略配置、免费额度、模块依赖及无需复刻的许可边界

2026-11-04 新增 [自有业务标签与管理来源](business-labels.md)，覆盖四类对象的独立分类及数据库模型来源展示。下表保留原生许可基线；该模块不等同于原生请求标签、任意 Team 校验回调或按标签 Usage 与预算能力，具体实施范围另记在 `CTRL-01`

同日新增 [固定窗口账号模型消费额度](model-budgets.md)，范围为零售钱包请求的预留、结算和释放，另记在 `CTRL-02`。已补充提前安排唯一下一窗口、普通用户只读展示及 [完整自然月自动续窗](monthly-budgets.md)。业务标签预算、优先级额度仍未实现，不改变原生商业功能判断

同日新增 [操作审计异步外投递](audit-delivery.md)，`CTRL-04` 先覆盖服务器预设单个目标、元数据投递、持久任务、失败处理和管理员状态页。它不等同于原生任意回调、推理日志目标、SMTP 或品牌模板，原生许可判断和下表范围仍保持原样

R11 新增 [固定 issuer 的自有 OIDC 控制台登录](oidc-sign-in.md)，`ID-SSO` 先覆盖显式已有账号绑定、管理会话及撤销，不复用商业自定义 SSO 处理器，也不改变下表原生 SSO 免费额度、调试入口或许可行为。真实企业 IdP、大规模登录、多 issuer、SAML、API JWT 和 SCIM 仍未因此验收完成。

R12 新增 [外部 API access JWT 映射](api-access-jwt.md)，`ID-API` 先覆盖固定签发方、短期 JWT、显式普通模型 Key 绑定、代际撤销和原计费权限。已完成隔离双 worker 验收，本地默认关闭；通用 OAuth2、裸 Bearer 互通、真实 IdP、多 issuer、SCIM 和大规模容量仍不在该批验收内。下表原生许可行为保持原样。

R13 新增 [SCIM Users 同步](scim-provisioning.md)，`ID-SCIM` 先覆盖固定来源的 User 子集、全新 customer 创建、版本化原子修改及停用/恢复/删除。凭据证明、并发发行、原生 OIDC/API JWT 接线及脱敏已限定本地验收，默认关闭；Groups、目录角色与既有账号迁移仍保留后续范围，不把 Users 子集写成全套 SCIM 完成

## 已有能力与排除项

零售钱包、动态销售定价、资源池路由、普通 Key、基础账号和团队、普通请求日志、常规用量、Redis 协调及多 worker 不整体列为重写对象。Key 轮换复用自有实现，IP 边界可复用成熟边缘控制但需验证部署，现有 Developers 满足客户接入文档需求但不承诺原生 Swagger 参数等价

普通 SSO 的五个 billable users 免费额度不等于社区账号总数上限。Auto Router 的高级能力额度不等于全部自动路由不可用。`allowed_routes` 仍执行的警告分支、原生许可席位与厂商计费遥测不作为独立业务功能重建

## 证据范围与更新规则

本基线来自当前源码，未对全部功能做运行验收，也未逐条比对已安装镜像。企业模块内部按识别出的功能族覆盖，不能宣称逐函数穷举。高级 metadata 的非空、清空及写入入口存在行为差异，不能概括为统一 HTTP 403

清单及任务 ID 保持稳定；后续重新审计时更新源码基线、证据和分批映射。每个后端和前端 ID 必须有且仅有一条处置记录；总括项可指向多个任务，不重复统计完成率。任务完成必须附实现提交、定向验证、部署与验收状态
