2026-11-05；基线 `617165b5f24916956fb4d1ae6b0d82415880310f`，实现 `92ad481fb578195dd5ae29af9b7ac78e0dd964d3`。状态 `validated_scoped_locally`：已合入本地 retail_portal、更新 UI 与源码并重启两个 worker；SCIM、OIDC、API JWT 和托管密钥保持关闭，未改生产或配置真实企业目录

## 已完成

独立目录入口增加 Group/成员的创建、查询、等值筛选、搜索、原子 PATCH、PUT、ETag 与软删除。成员必须是同来源中当前未删除的 SCIM User，不能把任意本地账号或另一个 Group 填入。组与成员的修改、凭据撤销和原生审计意图同事务，失败整体回滚

可选 access_group_external_ids 要求受管账号属于其中至少一个有效组，与原生 Key、模型、预算、资源池及钱包权限取交集。默认空名单不新增组资格要求；组不会自动授予原生管理员、组织、模型或资金权限。组检查并入已有受管身份 SQL，不给普通非受管 Key 增加本批 DB/RPC

移除成员、删除组或改变访问名单集合都会更新相关凭据 revision。重新加入、重新建组或放宽条件不会复活旧 Key、控制台会话或映射 API JWT。同一次 PATCH 先移除再加入也撤销旧凭据；当前已经接纳的流式请求继续完成和结算

组列表在 SQL 展开成员数组前限制每页最多 1000 个成员引用。请求 count 最多 100，实际 itemsPerPage 可更小，按实际返回数量继续分页。删除组、用户和成员关系保留必要墓碑，不靠删除回收历史配额
