# 原生事务审计与托管密钥验收

日期：2026-11-04

状态：本地双 worker 已启用原生事务审计，生产未改动。托管密钥在隔离原生网关验证，主本地仍默认关闭且未配置真实 Vault。实现提交与机器可读结果见 [R9 记录](r9-2026-11-04.json)

## 本批行为

自有 Key 轮换、用户自助改密和退出当前 UI 会话，均把原生变更与审计意图放在同一个原生 writer 事务。后台通过持久租约和不变事件身份桥接到 retail 审计，保留原发生时间，retail 提交后丢失确认不会重复业务变更或事件。队列满时受控变更整体回滚，不静默丢审计

改密保留当前会话，撤销其他 UI 会话并写入既有原生删除归档。事务内重新核验当前会话及密码 hash 快照，支持强制改密用户自救。审计仅有操作者、动作、数量、随机操作标识和发生时间，没有 Key、hash、密码或请求正文。组织审计不可读取这三类全站事件

独立 Vault KV v2 适配器后台预热和刷新本地快照，请求不访问 Vault。首版仅支持 Router 的 OpenAI 兼容 Chat 同步与异步调用，每次重试或 fallback 使用独立参数副本，客户端不能覆盖目标、凭据或授权 header。冷缓存、撤销和 TTL 到期返回通用不可用；非 Chat 托管部署在转发前拒绝

已知凭据错误在没有任何 provider dispatch 时释放预扣；前一个渠道已经 dispatch 后，后续凭据错误保留待核实状态，避免把不确定费用自动退回。该修改只扩展这一明确错误分支，不改变既有钱包 reserve/settle/release 核算

真实 viewer JWT 原先被前端简化为 Admin，用户列表和详情因此显示写按钮。本批把原始只读资格传到所有相关组件，隐藏创建、批量及编辑入口，并在角色降级时关闭旧编辑状态。管理员审计增加三类原生事件筛选；组织范围过滤掉不允许的全站动作

## 原生双 worker 与页面

隔离 PostgreSQL 只复制原生 schema，不复制账号或账本。原生网关使用两个 worker、独立 Redis、本地假 Vault 与固定 OpenAI 兼容上游，执行真实鉴权、零售预扣和结算，没有外部模型费用

两个 worker 都观察到密钥版本从 v1 切到 v2；100 次固定响应突发全部 200，用时约 1.17 秒，Vault 读取增加零次，上游恰好接收 100 次。管理员豁免 Router 的 A、B、普通部署 fallback 三次分别使用本渠道正确密钥，不削弱资源池限制。该有限样本不构成吞吐、尾延迟或生产容量认证

请求覆写的 api_base 在原生鉴权层被拒，其余凭据及 header 覆写被路由拒绝，均未转发。Vault 403、持续 503 后硬 TTL 到期，在两个 worker 均返回 503，没有增加扣费且预扣归零。服务端配置的先 dispatch A 再缺失引用场景，最终 503 并保留待核实预扣；这笔纯合成失败预扣只在取证后显式清理，不算自动退款证据

实际 HTTP 改密后，当前会话和普通 API Key 保留，其他会话在两个 worker 都返回 401。删除归档有正确 owner 与时间；Key 轮换后旧 Key 在两个 worker 返回 401，新 Key 读取模型目录成功。退出登录也跨 worker 生效。合成审计容量满时改密 503，密码、当前会话和事件数量保持不变；强制重置用户能自助完成改密

实际页面使用合成 viewer 和管理员验证列表、行菜单与详情。viewer 仅能复制用户 ID，管理员保留写入口。viewer 的实际退出产生安全审计事件，详情只有 kind 与 row_count。验收账号均退出，临时浏览器页已关闭。截图在工作区 outputs 的 r9-users-viewer-menu、r9-user-detail-viewer、r9-users-admin、r9-native-session-audit 与 r9-native-audit-detail 文件

## 本地启用与限制

主网关启用原生审计并显式重启两个 worker；readiness、liveliness、官网和组织财务页面 200，未认证私有路径 401。没有对主本地账号执行改密、轮换或新增授权。17 张既有财务表与 3 张原生身份表在启用前后 count/hash 完全一致，原生审计队列为零。1,058 个绑定文件的宿主机与容器 SHA256 一致，其中 UI 911 个；外投递仍暂停且没有真实目标或 secret

原生桥新增每 worker 最多两条、惰性打开的独立 retail 审计连接，不能宣称完全没有新增连接预算。部署和恢复边界见 [原生审计](../native-audit.md) 与 [托管密钥](../managed-secrets.md)

原生其他账号、渠道、价格及旧 Key 管理写入尚未全部桥接；托管密钥不含非 Chat provider、自动 Vault 登录续租、其他云或团队 UI。OIDC、SCIM、异步任务计费等剩余任务继续按清单推进，未把本批范围验收当成全部替代完成
