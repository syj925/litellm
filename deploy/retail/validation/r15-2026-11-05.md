# R15 请求策略与提示词本地验收

2026-11-05；基线 `9abce87d771205ea83d84e186093cf26d54a4438`，实现 `7e54aed7b68c755d5977c32f1abe874a6ae73e86`。状态为限定本地验收：源码和前端已经接入本地网关并重建两个 worker，新策略保持默认关闭，未改生产。使用方法见[请求策略说明](../request-policies.md)，逐项证据及哈希见[机器记录](r15-2026-11-05.json)。

## 已完成

原生账号、Virtual Key、精确公开模型可以绑定独立策略，限制 Chat、Responses、Messages 接口、输出上限及固定参数，并注入服务器保存的提示词。多条规则取交集和较小上限；固定值冲突、停用的已绑定策略或提示词会拒绝请求。解绑或停用绑定表示解除约束。关闭整个功能开关会明确停止执行本模块规则。

管理员页面包含策略、提示词和绑定三页。写入支持版本冲突检查和幂等回执，九类变更与原生审计同事务。普通用户、只读管理员和自定义认证无法读取私有管理数据；提示词列表及写入响应不返回正文，管理员明确打开单条编辑时才读取。

策略执行重新核对原生身份、模型权限和当前预算，保留 API JWT 等服务器证明。回调不能通过换模型、部署或路由参数绕过规则。提示词在报价时计入输入，最终发送前注入；诊断回调使用独立脱敏副本，实际计费回调保留原始用量、异常与终态事实。

联调修复了真实 Prisma 时间参数需要显式转换的问题，以及 Responses 适配器把低于 16 的输出上限自动提高的问题。后者现在提前拒绝，避免突破约束。另补成功响应 `instructions` 回显、错误回显、调试输出及线程上下文丢失时的日志保护。

## 验证结果

**898 项去重定向用例通过**：后端 488、真实 PostgreSQL 141、前端 269。最终后端组合运行期间源码和测试哈希未变；前端最后只增加协议限制说明，重复执行的 19 项组件测试不再次计数。OpenAPI 类型生成、生产 TypeScript、限定 lint/格式和前端生产构建通过。

**52/52 抽样故障变体被识别**，并非完整变异空间。存储 14 项在时间类型修复前，执行链路 15 项在 Responses 最小值保护前，入口及诊断 8 项在 WebSocket 保护前；新增边界另有专门回归、单独变异及最终组合验证。回调隐私 13 项使用最终源码。35 个 Python 改动文件共 105 项相对基线检查通过，未运行全仓语义 pyright。

真实浏览器完成 27 项检查、10 张截图：管理员登录、三个页签、创建/编辑/删除、提示词显式读取、暂停状态与零值、390 宽手机布局，以及普通客户注册登录后的入口隔离和零私有 API 请求。无页面脚本错误。账号菜单退出跳转未验收，两个独立浏览器上下文已销毁；最后的说明文字改动未重复整轮浏览器验收。

隔离原生双 worker 完成 12 组实际业务验证：三种接口的参数和私有提示词确实到达固定上游，Chat 流式终帧正常；六次普通成功调用全部结算，管理员公开模型调用受规则限制但不产生客户扣款。提示词冲突、路由覆盖、低输出上限、停用及陈旧模型权限在发送前被拒绝，错误请求释放预扣，无悬挂余额。规则变更在两个 worker 立即生效。

上游回显私有请求的错误已转成通用客户错误。可用凭据和保存提示词未进入 stdout、stderr 或四类诊断表。没有复制客户行、访问付费模型或绑定真实外部身份。新增实际流式端到端验证仅覆盖 Chat；Responses、Messages 的非流调用及流式隐私单测通过，其他真实流式互通仍需补验。

一次扩大到整个核心日志测试文件的探索运行因缺少 `vcr`、`requests_mock` 依赖而失败，未计为通过；最终只采用明确映射的回调、普通 SDK 和零售回归范围，不声称完整核心或全仓测试通过。
