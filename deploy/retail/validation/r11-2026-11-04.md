# R11 OIDC 控制台登录本地验收

日期：2026-11-04。基线 `ba3794eb`，完整实现 `5c03e495bbe94f38b34f1a22149f5b58a67e9a0d`。范围是 [固定 issuer 的显式已有账号 OIDC 控制台登录](../oidc-sign-in.md)，不修改原生商业门禁。

## 已交付

支持 code、nonce、S256 PKCE、RS256、固定 issuer/audience、可控端点 origin、浏览器绑定和一次消费。Discovery/JWKS 跨 worker 共享并有硬过期、租约、未知 kid 冷却及恢复。外部 email/role 不建号、不提权，身份映射只能由本站受控配置明确批准。

补齐显式/隐式标准端口等价，并从原始单一 Host 和受信 ASGI scheme 校验 origin，拒绝 Starlette URL 解析失败后静默回退 server 所掩盖的非法 authority；新增 26 个边界用例后，冻结源码完整单测重新通过。

原生 Key、不可变会话证明与签入审计同事务提交。每次管理请求核对当前权威，阻止 Key/绑定启停、密码/重置及支持或不支持角色循环恢复旧会话。新会话拒绝 LLM/MCP/BYOK/实验 blob；普通 Virtual Key 保持原有路径，不增加 OIDC DB/RPC。原生过期 UI 清理任务已在隔离环境验证覆盖这些 Key，生产使用前需配置，默认关闭的清理任务不能称已自动回收。

补修原有 Key 更新中 `metadata:null` 经策略归一化绕过服务账号保留字段保护的问题。OIDC 认证异常在 resolver span 内与原生异常出口先做通用投影，避免原生错误把 Key 哈希带入客户端、日志或失败遥测；普通认证异常兼容路径保留。

## 实际浏览器与脱敏

IAB 标签 26：真实点击 Organization sign in，经过本地 IdP 回调进入普通客户首页，侧栏仅显示其个人能力，直接进入客户钱包管理页被拒绝。管理员重新登录后安全回跳指定钱包管理页，并打开真实签入审计详情，仅出现 kind、row_count 和随机事件/操作 ID。两次浏览器会话均正常退出，临时标签已关闭。

OIDC 临时流程 Cookie 的 HTTPS Host 前缀、重复 Cookie 拒绝和 query/return_to 边界通过真实 ASGI HTTP 测试；浏览器验收使用明确许可的 loopback HTTP，不宣称已经完成真实 IdP 或生产 TLS 互通。原生兼容 token Cookie 仍需要 JS 读取，未伪称 HttpOnly。

最终原生 HTTP 复验对合并 stdout+stderr 以及 SpendLogs、原生 outbox、操作事件、请求追踪四张诊断表扫描，未检出本轮原始 code/state/nonce、UI JWT、opaque Key、其派生 SID 哈希和 client-secret 标记；已失效会话的客户端错误亦无 Key/hash。权威身份表、会话证明、原生 Key 和删除归档不属于这四张诊断表，不能把必要的原生权威哈希存储说成不存在。

## 主本地状态与限制

本地两个 worker 已激活本批源码/UI，1,076 个覆盖文件（含 911 个 UI 文件）的 hash 与主工作树一致。26 张既有业务、自然月和原生身份/审计表的数据指纹相同；不修改真实账号、绑定、密码、资金、价格或渠道。OIDC 开关保持 false，配置/密钥为空，三张 OIDC 权威表未创建。自然月与原生审计原有开关保留；托管密钥关闭、外投递暂停。

公共页面/状态/readiness 均为 200，关闭状态 start 只返回通用 303，未知状态 query 固定 400；私有 runtime 未认证 401、授权 200，`/qa/runtime` 在主站 404。主站登录页不再显示未配置的灰色 SSO 按钮，密码登录和注册入口保留，未在主站创建真实登录会话。

真实企业 IdP、SAML、多 issuer、API JWT、SCIM、自动账号生命周期及大规模登录容量仍未验收。关闭新登录不等于撤销全部已有会话；回滚必须保留新的 guard/权威表并明确撤销，不能返回不认识这些凭据的旧二进制。本批三个临时容器、隔离 PostgreSQL 的合成数据库和专用网络已清理，证据与脚本保留。没有生产部署、没有 20,000 RPM 或 80 核容量认证。清单仍为 implementation_in_progress，不把限定首版扩大为全部企业替代完成。
