## 当前行为

Key 自动继承当前原生 Team 的策略，与公开模型、账号及 Key 自身规则按 model → team → user → key 合并。接口权限取交集，输出上限取较小值，固定值冲突时拒绝，合并提示词仍受 16 KiB 总上限约束。管理页面增加 Team 搜索、分页、安全名称与 opaque UUID 绑定，普通客户不能读取私有管理数据。

当前 Team、成员模型、预算、别名与对象权限并入原有一次 writer 查询，后续原生检查复用这次结果，防止旧团队缓存重新带回权限。Team 缺失或停用时拒绝；新规则不会自动扩大 Key 的模型权限或钱包额度。原生 UI 的虚拟 Team 会话保留原范围，不作为实体 Team 绑定。

启用策略时，现有 Key 的实际父 Team 变更，包括显式清空，只允许当前可写全站管理员或主密钥身份执行。这个检查不依赖 Team 当前是否已有绑定，避免检查后再绑定的间隙。管理员合法移组后按当前 writer 中的父 Team 执行。该新增角色检查发生在原生写入准备之前，不声称持有角色锁直到整个旧写入事务结束。

Team 删除后，悬空 Key 被拒绝；有有效绑定的 Team ID 不能重建或改写身份时间。显式解除绑定后可以重建，但新实例取得不同目标 UUID，旧绑定不会自动复活。六张旧策略表、计数、版本和幂等回执兼容保留，无财务数据重写。

**38/38 抽样故障变体被识别**：存储 14、身份与继承 16、父 Team 管理及路由 7、日期 wire 回归 1，并非完整变异空间。前 14 项存储样本在最终日期修复前，后续独立变异、数据库用例及实际 Prisma 验证覆盖该修复。18 个 Python 文件共 54 项相对基线静态检查通过，未运行全仓语义 pyright。

真实 Prisma 联调发现：先创建日期为空的模型目标，再创建 Team、账号、Key 目标时，混合日期参数可能触发二进制绑定错误。已统一 ISO 文本及显式类型转换。同一引擎、同一事务完成八次新目标交错创建并全部回滚，保留数为零；最终实际 HTTP 按四种作用域顺序也通过。

真实浏览器完成 **39 项检查、13 张截图**：Team 专属搜索、27 条目标的 25+2 分页、UUID 安全投影、创建/关闭/删除绑定、固定目标编辑、390 宽手机布局，以及普通客户注册登录后的路由与侧栏隔离、零私有 API 请求。无页面脚本错误。OpenAPI 生成、生产 TypeScript、限定 lint/格式及 76 页生产构建通过。账号菜单退出跳转不在本轮范围，独立浏览器上下文已销毁。

隔离双 worker 完成九组实际业务验证。Chat、Responses、Messages 均验证普通 JSON 与 SSE：四层提示词顺序及上限确实到达上游，正文和终帧保留；11 次成功调用全部结算，无悬挂预扣。Team 策略暂停、原生停用和模型撤权在两个 worker 拒绝请求且不新增上游调用或预扣。全站管理员移组、自有 Key 轮换、旧 Key 撤销、Team 删除重建及旧绑定拒绝复活均通过。上游回显全部私有提示词的错误已转成通用客户错误并释放预扣。

原生 `/key/regenerate` 仍受商业门禁限制，实际拒绝没有改动凭据；这不计作新增移组 guard 的端到端证明。其共享准备入口由更新/轮换映射回归及变异验证。自有 `/retail/keys/rotate` 实际验证了保留 Team 与 Key 策略、撤销旧凭据。自有 API access JWT 仍拒绝 Team 目标，未扩大既有个人模型 Key 范围。

提示词及可用凭据未进入 stdout、stderr 或四类诊断表。没有复制客户行、访问付费模型或配置真实外部身份。测试环境先显式建立合法原生管理员，未放宽当前角色校验；源码覆盖补入 `auth_checks.py` 后才接受最终原生链路结果。

## 本地接入与边界

本地重建后，**31 张既有表指纹一致**，覆盖原 26 张财务/身份表及 Team、Membership、Budget、Model、ObjectPermission。1112 个覆盖文件与容器哈希一致，其中前端 917 个；20 项 HTTP 冒烟通过。策略和既有可选身份功能保持关闭，17 张可选权威表未创建，自然月额度及审计保持启用，外部投递仍暂停。三只测试容器、专用网络和临时绑定配置已清理。

创建 Team 绑定前必须一致升级全部 worker。R15 会忽略 Team 规则，不支持混跑；回退前必须通过 R16 删除全部 Team 绑定，关闭绑定不足以兼容旧管理 DTO。数据库没有自动拒绝旧进程的机制。

自有零售组织与原生 Team 是不同权限域，本批不把财务归属当作策略父级。Organization/Project 继承、通用护栏、任意 public/admin 路由配置及四个专项能力仍在后续清单；生产互通和 20,000 RPM 容量未认证。关闭功能会停止推理约束和新增移组 API 检查，已绑定身份的数据库保护仍保留。
