# 固定组织消费 CSV

组织消费实时预览下方可为已应用的组织和时间窗创建固定 CSV 任务。只有当前有效、可写的全站 Proxy Admin 能创建、查询和下载本人创建的组织任务；组织成员关系和组织管理员角色不授予这些财务权限

此入口同时要求 `RETAIL_ORG_FINANCE_ENABLED` 与 `RETAIL_REPORT_EXPORT_ENABLED` 生效，并沿用各自的组织和审计前置开关。关闭导出开关不影响个人钱包扣款；关闭组织财务开关不停止已经保存的有效请求组织归属采集

## 使用流程

在 Organizations 的 Consumption 中选择组织与北京时间窗口并点击 Apply window，确认实时结果加载成功后创建固定 CSV。创建操作使用已成功应用的窗口，尚未应用的日期输入不会改变导出条件，也不会把当前分页当作完整数据

任务列表只显示当前组织下由当前管理员创建的任务。Queued、Processing 表示后台尚在处理，Ready 才能下载。失败或过期任务不能下载；状态和下载响应不返回原始内部错误。认证下载入口支持 Range，每次请求都重新检查当前账号与组织状态，没有公开文件链接或带 token 的下载 URL

请求结果不确定时，用相同幂等键重试相同创建动作；不会新建第二份任务。改变组织或导出窗口属于不同操作，必须使用新的幂等键。相同键提交不同条件返回 409

## 快照口径

窗口以组织请求归属快照的接纳时间筛选，使用 `[start_at, end_at)`、UTC 存储和北京时间展示，币种固定 USD。最多 31 天、10,000 个归属请求；超限拒绝，不截断。已有更严格的报表容量配置继续生效

创建时在同一一致性事务内物化请求集合、账号、公开模型、接纳时间、三个归属版本、当时的结果状态和可核验的实际扣款。汇总由这份持久投影计算，覆盖完整集合。待结算、未知、冲突分别保留，金额留空；已结算的有效零金额保留为零

后台只读取固定投影生成 CSV，不重新查询当前钱包、成员关系或实时账本。创建以后才提交的请求或扣款不进入旧快照，即使其业务时间早于窗口终点。晚到结算、换组、改名、分页、生成重试和 worker 重启都不会改写已经创建任务的内容。需要更新结果时应创建新任务

固定内容不等于所有请求已经结算完成。包含当前北京时间自然日或未来区间的窗口标记 partial；即使是历史窗口，也应同时核对 pending、unknown 和 conflict。该 CSV 是消费快照，不包含充值、个人钱包余额、供应商成本或利润

CSV 文本字段处理公式注入。字段不包括 Key、凭据、请求正文、供应商地址、原始错误或价格表达式。组织名称按创建时冻结，不从当前名称拼装旧任务

## 权限与生命周期

查询和下载仅接受同一创建者、同一 URL 组织及当前可写管理员。未知或不匹配任务使用统一 404。角色降级、账号或凭据失效不能凭旧缓存会话继续下载；只读管理员也拒绝

组织停用会阻止创建、列表、详情及下载；重新启用后，未过期任务可按原权限读取。停用不会删除任务或改变其固定金额，也不修改原有个人钱包和请求归属。已经合法下载到本地的字节无法远程撤回

任务默认 24 小时后过期，访问立即按过期时间拒绝。清理在报表 worker 运行时分批释放投影和文件，过期任务元数据保留期沿用已有报表策略。停用 worker 或数据库故障可能延迟物理清理，不延长下载资格

## 队列、隔离与回滚

组织任务使用独立 jobs/rows 表，旧版账号报表 worker 不会误认或生成组织文件。两类任务共用现有报表连接池、受限线程池、快照槽和生成槽，账号任务与组织任务合计执行配额；没有为新模块增加推理或结算连接

创建、完成和最终失败记录同事务操作审计。组织报表事件不开放给组织委派角色，外投递仍仅使用受限事件元数据封装。持久化失败不返回成功创建，生成失败可按租约和有界重试恢复

关闭组织财务入口后组织任务停止生成，账号报表仍按原开关工作。关闭报表开关后两类生成均暂停。已存任务不会因此被重算，恢复支持该模块的版本后继续处理未过期任务

回滚不删除新表或已经物化的快照。旧程序不处理组织队列；若需要恢复生成，应重新启用支持本模块的版本。滚动升级期间先更新全部报表 worker，再开放入口，避免旧版账号 worker 不认识新组织任务而产生不同的合计并发统计

生产部署与本地功能验证分别记录。本模块不修改原生企业许可判断，不授予原生组织管理员权限，也不实现共享钱包。按具体自有组织 admin 成员显式批准的安全财务门户与任务属于独立的 [委派财务模块](delegated-finance.md)，不与本文管理员任务混用
